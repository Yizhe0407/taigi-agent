# TDX 免費方案兩天就會用完

公車資料全部來自交通部 TDX。免費方案的點數撐不過一個月，正式使用要升級。

| 方案 | 頻率上限 | 每月點數 | 夠用嗎 |
|---|---|---|---|
| 基礎會員（免費） | 5 次/分 | 3 點 | 不夠，約兩天用完，之後整個月查不到 |
| 銅級（200 元/月，學生減半） | 5 次/秒 | 200 點 | 夠，本系統每月約用 76 點 |

換方案後在 `backend/.env` 設定：

```dotenv
TDX_RATE_LIMIT=5/s     # 基礎會員用 5/min
```

## 系統怎麼省

- 所有 TDX 請求共用一個限速器，自己排隊，不會吃到 429。
- 使用者提問最多等 3 秒，等不到就用快取（到站分鐘數照現在時間重算）或回「暫時查不到」。
- 查「我要去虎尾」時，先用靜態站序挑出會到的路線（31 條 → 約 5 條）再查即時資料。

## 為什麼只用 TDX

以前還串過 TaiwanBus 和雲林 ebus，但都是爬別人的網站，常被封 IP 或掛站，已經移除。換資料源只需要改 `backend/providers/tdx_bus.py`。

實作細節見 [架構參考](architecture-reference.md) 與 `CLAUDE.md` 的「重要 Gotchas」。
