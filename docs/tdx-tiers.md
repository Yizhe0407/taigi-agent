# TDX 免費方案兩天就會用完

公車資料全部來自交通部 TDX。TDX 用「點數」計費：以公車 API 來說，大約每呼叫 1,500 次扣 1 點。免費方案一個月只有 3 點，這個系統兩天就用完，之後整個月查不到資料。

| 方案 | 頻率上限 | 每月點數 | 夠用嗎 |
|---|---|---|---|
| 基礎會員（免費） | 5 次/分 | 3 點 | 不夠，約兩天用完 |
| 銅級（200 元/月，學生減半） | 5 次/秒 | 200 點 | 夠，本系統每月約用 76 點 |

正式使用要升級銅級，然後在 `backend/.env` 設定：

```dotenv
TDX_RATE_LIMIT=5/s     # 基礎會員用 5/min
```

## 系統怎麼省

- 所有 TDX 請求共用一個限速器，自己排隊，平常不會撞到 429。真的碰到了，整把金鑰暫停一下再繼續。
- 使用者提問最多等 3 秒，等不到就先用快取的舊資料，沒有舊資料才回「暫時查不到」。
- 查「我要去虎尾」時，先用靜態站序挑出會到的路線（31 條 → 約 5 條）再查即時資料。

代價是用舊資料的那幾分鐘裡，公車誤點看不到。分鐘數本身會照現在時間倒數，不會念出過期的數字（見 [架構](architecture.md#限制)）。

## 為什麼只用 TDX

以前還串過 TaiwanBus 和雲林 ebus，但都是爬別人的網站，常被封 IP 或掛站，已經移除。要換資料源怎麼做，見 [架構](architecture.md#程式在哪)。
